# Priya Padma — Sens unique

Diaporama illustré pour présenter le roman de **Lauise Warinda** sur un stand au Salon du livre.

Sept diapositives en français, six aquarelles originales, une boucle de **70 secondes**, au format **16:9**. Fonctionnement entièrement hors ligne, sans serveur ni dépendance.

## Utilisation

Téléchargez le dépôt, extrayez le dossier et ouvrez **`index.html`** dans Chrome, Edge ou Firefox. Le défilement démarre automatiquement. Appuyez sur **F** pour le plein écran, **Espace** pour mettre en pause, et utilisez les **flèches** pour changer de diapositive.

Conservez le dossier `images` avec les fichiers HTML, CSS et JavaScript.

- [Mode d’emploi complet](LISEZ-MOI.md)
- [Prompts et références des illustrations](PROMPTS.md)

ISBN : **9798332039683**.

Les aquarelles ont été générées avec l’outil intégré imagegen. Elles constituent des interprétations artistiques de l’univers du roman ; elles ne représentent pas une couverture officielle.
